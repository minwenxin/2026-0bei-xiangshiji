# 制作游戏：动作、状态与验证

本轮范围：武汉热干面与嘉兴粽子；按用户最新确认，江南小笼包保持原状。两道为轻量游戏化演示，不是完整食谱或真实烹饪时长。

## 公共结构

`CookView.vue` 根据菜谱 ID 建立带 key 的 `CookingSession`。切换菜品会销毁旧会话；重做增加 key，同样销毁旧游戏。公共会话承担步骤板、单一气泡、下方状态区、保存与错误重试。具体动作分别由 `NoodleGame`、`ZongziGame` 管理；组件向公共会话报告状态，不直接写存储。菜名、素材清单、步骤、出餐与重试文案来自 `src/data/cooking.js`。

完成服务仍经 `stores/session.js`、`services` 写本机记录；仅保存成功才显示完成页。保存失败保留制作结果并允许再次出餐。离开页面后异步返回不再更新旧会话界面。

## 热干面

1. 点击漏勺，锅边显示装熟面的漏勺。按住鼠标左键或聚焦后按住空格，漏勺下移，水波反馈；释放提起并滴水。有效按住累计 1800ms 后还需完成 450ms 的提起沥水反馈。短按保留已有累计时间。此过程仅给已煮熟的面回温。
2. 点击芝麻酱，在碗口椭圆内按住左键拖动。有效局部距离累计拌匀量；点击、碗外起拖不计量，越出碗口即停止且不会自动恢复。固定空碗、独立面条和前沿层分开，局部面条窄片最多移动数像素，受碗口遮罩约束；筷子尖端跟随有效位置。松手/取消后位移归零。键盘方向键为替代搅拌动作，无旧滑块捷径。
3. 选择萝卜丁与葱花后，保留三个无字小圈与固定分布的配料短动画。重复点击不增加数量，重做卸载图层。减少动态效果时直接显示配料。

按住使用 requestAnimationFrame，帧间累计上限100ms，不补算后台时间；窗口失焦、页面隐藏、指针取消、移出、卸载均终止操作并清理。仅达到时间且主动释放、沥水完成才允许下一步。

## 嘉兴粽子

1. 选择粽叶，依次点击三个编号点折叠，叶层逐步变换，最后显示空漏斗；键盘可依次聚焦当前点并激活。
2. 依次点击糯米、肉馅、覆盖糯米，分别加入独立图层；重复上一步原料不增加图层，提前点击后续原料给出误选反馈。
3. 选择粽叶，依次点击两处包合点；再选择棉线，沿五个点的清晰路径拖动。`ThreadPath` 检查当前位置距当前线段与下一点的距离；离开路径停止，已完成节点保留，从最后节点可继续。键盘依次激活当前节点为替代包扎。完成包扎才可选择煮锅并点击入锅，1800ms简化煮制过渡后出餐。煮制期间失焦或隐藏会取消过渡，需重新点击入锅；离页销毁计时。

## 2026-11-05 用户试玩后的五项修订

本节替代上文中粽子装馅格位、锅选择与最终棉线的旧描述：

1. 初始案板为空；只有点击选择粽叶才挂载叶图与折叠点，重做回到空案板。
2. 叶兜开口内使用独立宽薄铺米层，并按叶兜开口裁切，取消小圆饭团效果；肉馅在底米之上、覆盖米之下。
3. 删除“覆盖糯米”格。装馅输入按“糯米→肉馅→糯米”推进，两次用同一格。尚未放肉时重复点糯米不增加进度，已经放肉后再次点糯米才覆盖，完成后不再增加图层。
4. 包扎仍沿五点路径操作，已收紧引导路径到粽身中部。完成后隐藏辅助路径，显示参考用户四角粽绕线结构补绘的绑线粽子，取消悬浮折线结。新素材来源及提示词见《依赖与素材》2026-11-05条目。
5. 删除工具格的“煮锅”和锅边入锅文字按钮。桌上深锅本身为带无障碍名称“点击桌上的锅煮粽子”的原生按钮；仅完成包扎后开放，点击或键盘激活即自动入锅并开始简化煮制。重复激活不重启计时，失焦后可直接再次点击桌上锅重试。

本轮改动集中于 `ZongziGame.vue`、`src/data/cooking.js`、`workstation.css`、制作测试辅助函数与 `cooking-guide.spec.js`；新增两张透明素材及更新本文和来源记录。保留热干面和已有未提交修改，不提交、推送、合并或部署。
