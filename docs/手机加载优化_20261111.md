# 手机加载优化（2026-11-11）

用户反馈正式站 `https://xiangshiji.netlify.app/` 手机打开慢。已用实际 Chrome 129 访问正式站，确认其请求完整 2,725,412 字节 TTF 和 529,360 字节首页图。网络访问成功，但本次不将自动化访问环境的时间当作用户手机实测。

## 修改

- 同一款字体转换为 WOFF2，按当前源代码中的文字分组：现有页面字符文件 412,476 字节，其他原字体字符文件 1,206,052 字节，通过互不重叠的 unicode-range 按需请求。保留原字体文件及来源记录，没有换字体。核对主体字符的字宽和边距与原始字体一致；浏览器确认额外字符会触发第二个字体文件，未静默丢字。
- 首页在 700px 及以下使用 picture/srcset：768 宽首图 86,338 字节、1200 宽首图 197,090 字节，宽屏仍用原高清图。图片仅缩小、重新编码，不重绘内容。
- 手机相框使用 512 宽版本（73,136 字节）；早餐笺显示使用 400 宽版本（40,160 字节）；热干面及粽子照片增加 480 宽候选（39,316／28,246 字节），由浏览器依显示尺寸选择。原始照片、完整水印文件及现有页面裁切规则保留。
- 图片增加异步解码，原有懒加载及首图高优先级保留。未引入网页运行时依赖、样式库或第三方素材。

## 同条件对比

本地正式构建、实际 Chrome 129、390×844 CSS 像素、DPR 2、网络缓存关闭。CDP 模拟 150ms 延迟、下载 250,000 字节/秒、上传 125,000 字节/秒。各一次测量，非统计平均；这些参数为本项目测试选择，并非比赛指定数值。时间包含页面导航、对应资源下载和解码。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 首图解码就绪 | 9,741 ms | 3,073 ms |
| 网页字体就绪 | 18,524 ms | 4,332 ms |
| 至字体就绪时完成的网络传输量 | 4,405,549 字节 | 891,874 字节 |

约减少 80% 的上述传输量。结果说明同条件下的资源优化效果，不保证不同运营商、设备或 Netlify 线路具有相同耗时。此次本地复测与真实网站更新分开：上传分支后仍需正式部署才对原网址生效。
