# 地图居中与省名修正 · 2026-10-27

修改前已阅读比赛规则清单和工程AGENTS.md。用户指出地图偏左，部分省名不完整。

## 原因与修正

原始主图轮廓的横向范围为35到712.64，中心373.82；画布宽940，主图视觉中心未与画布中心对齐。本轮将整个主图层平移96.18，命中区、边界、浮起色块、名称及引线同步，确保点击位置一致。主SVG在容器内居中，最大1120px，避免大屏过度放大。南海附图向右适度挪动，保留完整内容。

原先省名和色块按省份交错绘制，后绘制的相邻色块会遮挡早先省份名称。现在先绘制所有色块，再绘制高亮，最后统一绘制全部省名与引线。名称层不接收鼠标事件，保持原有点击与键盘探索；高亮省名同步抬升，不添加跟随提示框或侧栏。

## 核对
