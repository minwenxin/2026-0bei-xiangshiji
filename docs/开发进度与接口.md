# 正式开发起点 · 2026-10-27

## 已建立

- 从空的私有 GitHub 仓库建立独立工程；原样板在工程外保留。
- Vue 3 + Vite + Vue Router，页面懒加载，无预设样式库。
- 独立首页、地图无跟随提示框无侧边预览、地区列表筛选、统一食物详情。
- 制作与故事独立，发现入口位置固定，故事阅读进度保存，结尾才收纪念物。
- 广场本地推荐/评论/喜欢/收藏、投稿独立、个人查看、基础图片预览与本地保存。
- 错误、空状态、丢失内容、路由加载失败与本地保存失败反馈。

## 下一阶段

1. 队友确定正式收录食物名单与核验资料；现有三条仅为开发内容，未扩充未经核验的假内容。
2. 获取正式食物/角色/场景/纪念物素材；制作当前角色与台面操作视觉仍需完善。
3. 将样板食材文字按钮逐步替换为素材移动和制作结果的清楚反馈。
4. 细化个人资料（当前本地访客）、投稿修改重提和状态查看；不虚构真实管理员审核。
5. 确认后台负责人和技术方案后实现真实服务适配；首先完成真实评论、帖子与持久化闭环。
6. Chrome 129、慢网和大中小屏专项；地图合法授权及表达核验；文档、完整/匿名包准备。

## 拟定接口契约（尚未连接）

| 业务 | 未来接口 | 当前入口 |
| --- | --- | --- |
| 美食列表/详情 | GET /foods、GET /foods/:id | data/foods.js |
| 省级信息 | GET /regions | data/china-map.json |
| 推荐发布/查询 | POST /posts、GET /posts、GET /posts/:id | stores/session.js → updateProgress |
| 评论 | GET/POST /posts/:id/comments | progress.comments |
| 收藏/喜欢 | PUT/DELETE /me/marks/:type/:id | mark(kind, type, id) |
| 故事发现、阅读、领取 | POST /me/stories/:id/discover、PATCH /me/stories/:id、POST /me/stories/:id/collect | findStory/readStoryPage/takeMemento |
| 制作完成 | PUT /me/cooking/:id | completeRecipe |
| 投稿与状态 | POST /submissions、GET /me/submissions | progress.submissions |

当前仅使用异步本地存储适配器。以上接口是设计草案，不是已实现的 HTTP 后端。后端接入需将聚合进度保存替换为对应业务调用，并由服务端验证身份、内容、故事阅读进度、上传和权限；不能只修改环境变量便宣称上线。

## 验收原则

先执行核心业务测试，再构建和浏览器流程核对。比赛要求优先；每轮动手前读清单。测试证据与未覆盖环境写入检查记录，不以构建成功冒充比赛环境验收。
