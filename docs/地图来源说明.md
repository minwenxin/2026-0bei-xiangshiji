# 中国省级交互地图

更新：2026-10-27。

## 数据来源与边界

- 下载地址：https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
- 提供方：阿里云 DataV GeoAtlas，官方说明 https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/ 记载数据来自高德开放平台，仅供学习与交流使用。
- 原始文件：assets/china-provinces.geojson，34个具名省级要素及一个断续线要素，合计35个要素。
- 保留源数据全部多边形环；未手工重画、简化省界。build-map.mjs 使用 Albers 等积圆锥投影（标准纬线25°、47°，中央经线105°）生成 assets/china-map-data.js。
- 南部图形以南海诸岛附图呈现，保留台湾、香港、澳门及源数据的岛屿和相关海域线段。地图内容属于源数据表达，不是助手独立核验后的官方底图。

官方标准地图服务 https://bzdt.ch.mnr.gov.cn/ 与 https://bzdt.tianditu.gov.cn/ 本次连接失败，未取得官方标准底图与审图号。当前成果是省级地理边界交互版，不声称已完成用户所指的“官方审定标准地图”替换，也不编造审图号。正式参赛公开展示前仍须核对数据授权、时效和地图审核要求。本次只用于既定本地开发演示。

## 实现与依赖

map.js、map.css 为本项目自写。没有引入地图运行库、预设样式库、在线瓦片、访问密钥或第三方脚本。浏览器加载预生成的本地 SVG 路径数据，支持直接打开 index.html。

地图为固定省份命中区域；悬停在独立的、不接收指针的覆盖层绘制同一边界，向上移动6个SVG单位并投影。这样视觉浮起不会改变鼠标命中区域。名称提示随鼠标移动并限制在容器内。键盘聚焦也显示提示，Enter/空格选择，Escape退出；减少动态效果时取消位移。手机提供34个地区的下拉选择与3个已开放地区快捷入口。

已开放湖北、江苏、浙江沿用原省份美食列表，其他地区明确显示整理中，不虚构食物内容。
