# 依赖、样式与素材

## 依赖用途

| 名称 | 用途 | 是否提供预设样式 |
| --- | --- | --- |
| Vue 3 | 页面组件与响应式状态 | 否 |
| Vue Router 4 | 页面路由与页面懒加载 | 否 |
| Vite 7 | 本地开发和构建，生产目标设为 Chrome 129 | 否 |
| @vitejs/plugin-vue | 编译 Vue 单文件组件，开发依赖 | 否 |
| @playwright/test | 使用本机 Chrome 验证页面和业务流程，仅开发测试 | 否 |

以上工具的精确版本锁在 package-lock.json。传递依赖随锁文件管理；前端没有引入 UI 样式库、地图样式库、React Bits 视觉组件或第三方脚本 CDN。代码与样式由本项目编写。

## 素材

本次正式工程迁移现有已确认的“样板页sol整合版”插画，而非重新生成。该样板的全新素材创作过程见《样板素材说明.md》。public/assets 中仅保留运行所需的 JPG 和 WebP，不上传用于编辑的原始 PNG。

hero-alley.jpg：首页场景；alley.jpg：巷口札记；三个 sticker.webp：对应美食；story-1/2/3.jpg：虚构故事分镜与制作占位。它们仍是 AI 辅助临时素材，不称作队友画手正式作品，不声称赛事已允许 AI 素材。

省级边界在 src/data/china-map.json，来源及许可待确认事项见《地图来源说明.md》。地图不使用网络请求加载第三方数据，不作为已审定的官方标准地图。

系统字体只引用、不打包分发。食物文案来源状态记录在各条 data/foods.js 的 sourceStatus，正式收录前需替换为核验资料。
