# 巷食记 · 正式前端工程

围绕“市井烟火·百味人间”，以地方美食探索、精选制作、隐藏故事和纪念物收藏连接各地日常。

本仓库是正式开发工程的起点，当前内容与数据服务仍为前端本地演示。原始样板保留在仓库外，不将测试截图、原始 PNG 和比赛历史资料混入项目。

## 每次修改前

先阅读 [比赛规则与开发检查清单](docs/比赛规则与开发检查清单.md)，再阅读 [网站构想](docs/网站构想.md) 与用户最新决定。开发约束记录于 [AGENTS.md](AGENTS.md)。团队负责开发分工；本工程不重新安排成员职责。

## 安装与运行

要求 Node.js 22.12 或更高版本，推荐本机已安装的 Node 24。

```sh
npm ci
npm run dev
```

浏览器打开终端给出的地址，默认 `http://127.0.0.1:5173`。这是 Vue 工程，需要服务运行，不能像旧静态样板那样双击 index.html。

```sh
npm test                 # 核心业务规则和存储错误核对
npm run build           # 生成 dist，目标 Chrome 129
npm run preview         # 在 4318 端口预览构建结果
npm run test:browser    # 使用电脑已有 Chrome 检查构建结果，先运行 build
```

浏览器测试默认使用已安装的 Google Chrome，不会自动下载浏览器；未安装 Chrome 的电脑可调整 `playwright.config.js` 的 channel，或按 Playwright 官方文档配置浏览器。测试会自行启动并关闭预览服务，运行前确认 4318 端口未被占用。

## 工程结构

```text
src/
  components/   公用美食图、卡片、互动按钮、空状态
  data/         美食、故事、制作配置和省级地图数据
  domain/       进度、收藏、故事发现与领取规则
  router/       独立页面与懒加载路由
  services/     本地数据服务；后续真实接口替换处
  stores/       共享会话状态和保存错误反馈
  styles/       自研样式，沿用已确认的样板视觉
  views/        首页、地图、详情、制作、故事、社区、我的等页面
public/assets/ 运行所需的本地插画
docs/          比赛要求、需求、素材与开发说明
tests/         核心规则测试和浏览器流程核对
```

## 当前可体验

- 首页独立，地图按省进入列表，城市与类别筛选，三个统一美食详情。
- 地图保留高亮和点击；无跟随提示框，无侧边预览栏。
- 热干面三个关键制作步骤，误选恢复、重做和完成记录。
- 旧纸条单独发现虚构故事，阅读进度与纪念物分别记录，彩蛋收藏以物件陈列。
- 广场区别团队策划演示内容与本地帖子，文字及小图推荐预览、点赞、收藏与评论。
- “我的”按收藏/喜欢、美食/帖子分类，查看自己的帖子及演示投稿记录，支持导出本地 JSON。

## 数据和真实上线边界

没有真实账号、跨设备同步、公开发帖、多人评论、后台审核。用户数据保存于当前来源下的 localStorage，版本键为 `xiangshiji:formal:v1`，与旧样板记录隔离。清理浏览器数据会丢失记录，开发端口和预览端口的记录也相互独立。

保存失败时不更新“已保存”状态并保留输入；图片限制 1 MB，存储容量由浏览器决定，空间不足有明确反馈。页面访问 `stores/session.js`，由 `services/api.js` 选择数据适配器；真实服务的拟定契约见 `docs/开发进度与接口.md`。没有自动连接未来后台的隐式配置。

## 比赛与素材

无预设样式库或现成视觉组件。Vue、Vue Router 用于工程和路由，Vite 用于开发构建，Playwright 仅用于开发测试；完整用途见 `docs/依赖与素材.md`。AI 插画沿用用户已确认样板，全部注明临时用途，地图来源与待确认事项保留说明。正式食品资料、画手素材和故事分镜待队友交付。

构建目标为 Chrome 129 不等于已完成该版本验收。慢网专项、Chrome 129 实机、IE口径、地图授权与表达、真实资料来源、比赛组别和匿名包命名等仍需后续核对。尚未生成完整/匿名两套比赛包。未部署或公开发布网站。
